# Практическая работа №2: Каталог товаров на SCSS

# trpo-pr02-Kinakh

Адаптивный каталог товаров, разработанный с использованием семантических тегов HTML5, сеток CSS Grid и предпроцессора SCSS. Содержит шапку с навигацией, боковую панель фильтров, сетку из 12 карточек товаров, информационный блок «О каталоге» и подвал.

---

## Технологии
* **HTML5 — семантическая структура страницы
* **SCSS/Sass** — переменные, функции, миксины, вложенность, разделение на partial-файлы
* **CSS3** — CSS Grid, Flexbox, адаптивная верстка с медиазапросами
* **npm** — автоматизация сборки SCSS через npm-скрипты
* **Git** — управление версиями

---

## Структура HTML
`body` — главный контейнер
* `header` (`.site-header`) — шапка: заголовок (`h1`) и навигация (`nav` со ссылками `#catalog`, `#about`)
* `main` (`.container`) — основной контент страницы
  * `div` (`.layout`) — двухколоночная Grid-сетка
    * `aside` (`.filters`) — боковая панель с формой фильтрации (`form`)
    * `section` (`#catalog`) — раздел каталога с 12 карточками товаров (`article.card`)
  * `section` (`#about`) — раздел «О каталоге»: описание и категории (`figure` + `figcaption`)
* `footer` (`.site-footer`) — подвал страницы с копирайтом

**Семантика:** `header`, `nav`, `main`, `aside`, `section`, `article`, `figure`, `figcaption`, `footer`.  
**Иерархия заголовков:** `h1` → `h2` → `h3`.

---

## SCSS & CSS-приёмы
* **Модульная архитектура (Partials):** логическое разделение стилей на файлы с `@use`
* **Переменные (`_variables.scss`):** единый источник цвета, радиусов, отступов и ширины контейнера из `theme.json`
* **Функция `space($n)` (`_functions.scss`):** расчет отступов, кратных базовому шагу
* **Миксин `@mixin focus-ring` (`_mixins.scss`):** стилизация состояния `:focus` для доступности (Accessibility)
* **CSS Grid (`_layout.scss`, `_card.scss`):**
  * Главный каркас `.layout`: панель фильтров (250px) + область каталога (`1fr`)
  * Сетка карточек `.cards`: 3 колонки (`repeat(3, 1fr)`)
* **Flexbox:** позиционирование элементов в шапке, форме фильтров и блоке «О каталоге»
* **Два адаптивных Breakpoint (`@media`):**
  * **<= 900px:** перенос панели фильтров наверх (`grid-template-columns: 1fr`), перестройка карточек в 2 колонки
  * **<= 560px:** перестройка карточек в 1 колонку, вертикальная ориентация навигации в шапке
* **Валидация полей (`&:invalid`):** подсветка полей ввода при ошибке (например, отрицательная цена)
